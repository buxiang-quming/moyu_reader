# 摸鱼阅读器 · Moyu Reader

> Windows 桌面透明浮窗小说阅读器。屏幕上**只有文字**，没有边框、标题栏、背景块。
> 鼠标移上去就有，移开**立刻消失**，鼠标再回到那块地方又会出现。`Ctrl+Alt+Q` 一秒清空，不留痕迹。

**零第三方依赖 · 绿色免安装 · 不联网 · 不写注册表**。只用 Python 自带的 `tkinter` 和 `ctypes`，解压即用。

## 它解决什么问题

上班想看书，但不想让人一眼看出你在看书。常见做法是把窗口调小、调半透明，但**窗口本身就是证据**——宽高、边框、任务栏图标都在。

这个工具的思路反过来：**根本不要窗口**。它在桌面最上层铺一张透明画布，只把字画上去。背景可以是纯透明（只留文字），也可以是极淡的半透明块。配合鼠标穿透和老板键，别人从背后看过来，屏幕上就是一片空白或者一个文档。

## 特性

| | |
|---|---|
| **只有文字** | 颜色键透明，抠掉背景只留字；也可以选淡底+文字 |
| **即移即隐** | 移开默认 0ms 消失，移回原位置立刻出现，不用去找热区 |
| **老板键** | `Ctrl+Alt+Q` 清空渲染并隐藏，鼠标扫过原位置也不会把它扫回来 |
| **鼠标穿透** | `F3` 让点击穿过窗口直接落到下面的软件上，边看边操作别的程序 |
| **本地导入** | `.txt` 自动识别 UTF-8 / GBK / GB18030 / Big5 / UTF-16；`.epub` 按 spine 顺序解析，目录就是书里的目录 |
| **网址导入** | 粘贴目录页链接，自动启发式识别章节列表和正文（不内置书源） |
| **进度记忆** | 记住读到哪本书、第几章、屏内位置，下次双击直接续上 |
| **书架 / 设置** | 卡片式书架，三页签设置，三套配置可切换，快捷键可改 |
| **简繁转换** | 内置约 500 字对照表，繁体书源可一键转简体 |

## 启动

双击 **`启动.bat`**。

启动后先弹出的是 **书架**，不是阅读窗。双击一本开始读，书架自己收起来，屏幕上只剩文字。

> 看完想换书：`Ctrl+B` 再把书架叫出来。

> `启动.bat` 和 `start.bat` 内容完全一样，后者是纯英文名。万一中文文件名在你的系统上报「Windows 找不到」，双击 `start.bat`。
>
> **重复双击不会多开**：它发现已经在运行，就会把书架（或正在读的窗口）叫回到前台，所以「点了没反应」现在不会有了。
>
> 双击真的没反应就用 `调试启动.bat`，有控制台输出，日志在 `data/error.log`。

## 第一次用

1. 双击 `启动.bat` → 弹出书架
2. 点 `＋ 添加` 选 txt 或 epub（可多选），或点 `＋ 网址` 粘目录页链接
3. 双击书封面 → 书架收起，文字出现在屏幕右上角
4. 鼠标移开立刻消失；移回原来那块地方（不止屏幕角落）又会出现；下次打开自动接着上次的位置

## 设置面板

### 阅读器外观

- **快速预设**：浅淡（白底页）/ 更淡（几乎隐形）/ 深淡（深色 IDE）/ 只留文字 / 只留文字·深色
- 文字颜色、背景颜色（点色块取色）
- 背景透明度滑块
- 字体大小、字体、行间距（倍数）、段间距
- 保留格式、展示百分比
- 窗口宽度 / 高度（直接填数字）
- 顶部进度条、每次翻页行数

### 阅读器功能

- 移入延迟 / 移出延迟（毫秒）。**移出默认 0 = 立刻隐藏**；想宽容一点就填 300~500
- 右下角保留：鼠标停在屏幕右下角这块区域时不隐藏
- 鼠标翻页（开 = 单击正文翻页）
- **单击钉住（默认关）**：开了以后单击正文就把窗口固定住。默认关，因为太容易误触——
  点一下正文（想滚动或聚焦）就被钉住，之后移开永远不隐藏，很难想到是这个原因。
  用 `Ctrl+P` 也能钉住，不管这个开关开没开
- 窗口可移动（关掉 = 锁定位置，防手滑）
- **点击穿透**：窗口照常显示，但鼠标能穿过去点下面的 Excel
- **滚轮行数（默认 1 行）**：滚轮转一格往下走几行。窗口本来就只显示三四行，调大很容易「一滚就是大半屏」
- 滚轮延迟、滚轮方向反转
- 自动翻页间隔、连续翻页
- 简繁转换（不转换 / 繁转简 / 简转繁）
- 快捷键自定义：上/下一页、上/下一章，每个动作可绑 3 个键

### 其他

- 老板键、唤出键、穿透键（点按钮直接录制组合键）
- 唤出热区（角落位置 + 宽高）
- 隐藏任务栏图标
- 清除阅读进度 / 打开数据目录 / 重置当前配置

改动**即时生效**，可以一边调一边看效果，满意了再点「保存并关闭」。

顶部 `≡ 配置1 ▾` 可以新建多套配置（比如「看文档」一套、「看代码」一套），一键切换。

## 鼠标穿透（F3）

这是 v2 里最实用的一条。

窗口浮在你的 Excel 上，你想改个单元格——但鼠标一动就被窗口挡住了。

按 `F3` 开启穿透后：**窗口还在那儿显示文字，但鼠标直接穿过去操作下面的软件**。

穿透状态下窗口收不到任何点击，所以要用 `Ctrl+Alt+E` 或书架上的按钮切回来。

## 导入书籍：txt 与 epub

`Ctrl+O` 或书架里的 `＋ 添加本地书籍`，两种格式可以混着多选。

### TXT

编码自动识别（UTF-8 / GBK / GB18030 / Big5 / UTF-16），章节按「第 X 章」「卷三」「Chapter 12」「（1）」等标题识别；实在没有章节结构就按 3000 字自动分页。

### EPUB

EPUB 本身就是个 zip，用标准库解，不装任何第三方包。

- **按 spine 顺序读**，不是按文件名排序——这是出版社认定的阅读顺序，跟书里的目录一致。
- 一个 XHTML 文件通常就是一整章；如果一个文件里出现多个 `<h1>`~`<h3>`，会按标题再切成多章。
- 章节名优先取文件内的标题标签，没有就回落到 NCX / EPUB3 nav 里的目录名。
- 图片、CSS、字体、脚本全部跳过——阅读窗只显示文字，所以**纯图片扫描版打不开**（会明确报错，不会给你一片空白）。
- 书名取 `dc:title`，不是文件名。

实测一本 187 万字的合集 EPUB：694 章，解析 0.8 秒。

## 关于透明度，得说清楚

参考产品里有 `rgba(244,245,247, 0.3)` 这种写法——那是浏览器内核的能力，背景半透明但文字不透明。

**tkinter 做不到**。它的 `-alpha` 是整窗透明，文字会被一起打淡。

所以这里给你两个真能用的模式：

- **带底（半透明）**：浅色底 + 整窗透明度。效果和参考产品很接近——字会跟着变淡，在白底页上看起来就是「淡灰小字 + 几乎看不见的底」，正是那张阅读效果图的样子。
- **只留文字（抠背景）**：用颜色键把背景完全抠掉，屏幕上只有字，透明度对文字无效。最隐蔽，但文字会和下面的内容叠在一起。

同理，**文字间距（字距）做不到**，tkinter 的 Text 不支持。给的是行间距和段间距，这两个真生效。

## 网址导入

`Ctrl+U` → 粘贴**目录页**网址 → 回车。

它自己做四件事：找书名、找目录、抓当前章、缓存到本地。

**要注意：**

- 只支持能直接打开的静态目录页。要登录、要验证码、纯 JS 渲染的抓不到。
- 站点改版后可能失效，它靠启发式找 `<div id="content">`、`<dl>` 这类结构。
- 这是**通用解析器**：不内置书源、不预置站点、不批量下载。看什么、从哪看，自己判断，版权自己负责。

抓取失败会告诉你失败在哪一步，不静默失败。

## 常见问题

**双击后什么都没有？**
不可能——现在双击第一眼就是书架。
如果书架被关掉了，鼠标移到屏幕右上角，或按 `Ctrl+Alt+Z`，会出来一个提示窗（提示怎么再打开）。
如果连这也唤不出来，**再双击一次 `启动.bat`**——它会去叫醒已经在跑的那个实例。

**我「关掉」了它，但它好像还在？**
关窗口右上角的 ×，关掉的是书架或设置面板。还在跑就按 `Ctrl+Alt+Z` 叫回来。
想真正退出：**在正文上右键 → 退出**，或书架顶栏的 `退出程序`。

**文字看不清 / 和背景糊在一起？**
`Alt+滚轮` 调文字深浅，`Ctrl+滚轮` 调背景深浅，或设置里换预设。

**移开鼠标就消失，没法点目录？**
按 `Ctrl+P` 钉住（右下角会显示「已钉住」），钉住期间移开也不会消失；再按一次松开。
想让它慢一点消失：设置 → 功能 → 移出延迟填 300~500（默认 0 = 立刻）。

**移开鼠标它就是不隐藏？**
之前有个坑：单击正文会「钉住」窗口，钉住后移开永远不消失，而提示只是一闪而过的淡字——
点一下正文（想滚动或聚焦）就中招了，看着像坏了。
现在单击不再钉住，钉住改用 `Ctrl+P`，且右下角**常驻显示「已钉住」**。
还是不明原因就在正文上**右键 → 为什么没自动隐藏？**，它会直接把当前挡住隐藏的原因说出来。

**鼠标回到原来有字的地方，怎么不出现了？**
会出现的。只有按过老板键（`Ctrl+Alt+Q`）之后不会——那时必须用 `Ctrl+Alt+Z` 或移到屏幕右上角热区，
免得鼠标随手一扫就把清掉的屏又扫回来。

**鼠标点不到窗口了？**
开了鼠标穿透。按 `Ctrl+Alt+E` 或 `F3` 切回来。

**老板键没反应？**
可能被别的软件占了。设置 → 其他 → 点老板键右边按钮重新录一个。

**公司电脑没装 Python？**
装一个，或把 `C:\Users\<你>\AppData\Local\Programs\Python\Python37` 整个目录拷过去，改 `启动.bat` 里的路径。

**epub 打不开？**
两种可能：一是纯图片扫描版（没有文字层），会提示「没有可提取的文字」；二是文件本身不是标准 EPUB（比如其实是 PDF 改了后缀），会提示「不是有效的 EPUB」。
DRM 加密的电子书（Kindle、部分电商购买的书）也打不开，这个无解。

**大文件卡不卡？**
实测：剑来 1341 万字 1228 章 0.67 秒，轮回乐园 1438 万字 3332 章 0.85 秒。打开时等一下，之后翻章是瞬时的。

## 边界

这工具做的是**降低可见度**，不是**对抗监控**。

- 不做：反截屏、反录屏、进程名伪装、注入其他程序、绕过上网认证。
- 透明窗口在截屏审计面前没有意义——DLP/EDR 抓的是屏幕像素和进程列表，不是窗口的透明度。别把「看不见」当成「查不到」。
- 在什么设备、什么时间、看什么内容，由你判断。
